# Selenium IDE Web Testing Project

## About the Project
This is a university project for the Verification and Validation course.

The goal of this project is to test the login and logout functions of a web application using Selenium IDE.

Selenium IDE was used to record and run test steps in the browser without writing code.

## Tool Used
- Selenium IDE

## Use Cases

### 1. Successful Login
**Description:** The user enters a correct username and password.

**Expected Result:** The user logs in successfully and sees the Products page.

### 2. Login with an Incorrect Password
**Description:** The user enters a correct username and an incorrect password.

**Expected Result:** The system shows an error message and does not allow the user to log in.

### 3. Login with Empty Username and Password
**Description:** The user tries to log in without entering a username or password.

**Expected Result:** The system asks the user to enter a username.

### 4. Login with an Empty Password
**Description:** The user enters a username but leaves the password field empty.

**Expected Result:** The system asks the user to enter a password.

### 5. Logout
**Description:** The user logs in and then clicks the logout option.

**Expected Result:** The system returns the user to the login page.
